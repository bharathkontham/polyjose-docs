# Credits for the polyjose brand artwork

## Inter (lettering)

The lettering in `brand/src/` (the "polyjose" wordmark, the tagline and the platform names in the social images) is set in **Inter Display SemiBold**, from **Inter version 4.1**.

- Copyright (c) 2016 The Inter Project Authors (https://github.com/rsms/inter).
- Licensed under the **SIL Open Font License, Version 1.1**: https://openfontlicense.org
- Source: the Inter 4.1 release archive, https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip, file `extras/ttf/InterDisplay-SemiBold.ttf`.
- sha256 of the release archive: `9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`. It was checked before the font was used.

The glyphs were converted to outlines, as SVG path data, by [`tools/outline.mjs`](tools/outline.mjs), which reads the glyph outlines with fontkitten 1.0.3 (MIT). The artwork contains only those paths. No font file is redistributed: none is stored in this repository, embedded in the artwork or served by the site.

## The mark

The keyhole p mark is original geometry drawn for polyjose. No third-party artwork is used in it or in any other file in `brand/`.
