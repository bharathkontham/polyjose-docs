## Notes

### Updates by RFC 9864

RFC 7518 and RFC 8037 are updated by [RFC 9864](https://www.rfc-editor.org/rfc/rfc9864). It registers fully-specified algorithm names, such as `Ed25519`, and sets the older `EdDSA` identifier to Deprecated. polyjose supports both: use `Ed25519` for new tokens, and `EdDSA` for tokens and peers that already use it.

### Duplicate member names

[RFC 7515 §4](https://www.rfc-editor.org/rfc/rfc7515#section-4) and [RFC 7519 §4](https://www.rfc-editor.org/rfc/rfc7519#section-4) let a parser either reject JSON with duplicate member names or keep only the last one. polyjose always rejects duplicates, in headers, claims, JWKs and every other JSON it reads, with `InvalidJson`. Two parsers that keep different duplicates could otherwise read the same token differently.
