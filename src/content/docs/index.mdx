polyjose is being built as a pure-Rust implementation of JWS, JWE, JWK and JWT. One core, with bindings for Node.js, WebAssembly, Kotlin and Swift, is designed to give the same results, the same defaults and the same errors on every platform. Each binding is meant to pass the same conformance tests before 0.1.0 is released.

<Aside type="caution" title="Pre-1.0, not published yet">
polyjose is pre-1.0 and not published yet: there is no release on crates.io, npm or Maven Central and no tagged Swift package, and the APIs may change before 1.0. The get-started pages say what they will cover when 0.1.0 is published.
</Aside>

## Security first

polyjose is designed around RFC 8725: verify and decrypt take an explicit list of allowed algorithms, `none` is never accepted, and keys are bound to their algorithm family. These pages explain what that protects against and what it doesn't.
