polyjose is a pure-Rust implementation of JWS, JWE, JWK and JWT. One core, with bindings for Node.js, WebAssembly, Kotlin and Swift, gives the same results, the same defaults and the same errors on every platform. Every binding passes the same conformance tests.

## Pick your platform

Install the package for your platform and import it into your project. Each guide then signs and verifies a first token.

## Security first

polyjose is designed around RFC 8725: verify and decrypt take an explicit list of allowed algorithms, `none` is never accepted, and keys are bound to their algorithm family. These pages explain what that protects against and what it doesn't.
