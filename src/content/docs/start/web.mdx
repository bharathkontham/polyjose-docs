Use polyjose in browsers and bundlers through WebAssembly (`@polyjose/wasm`). The same package also runs in serverless and edge runtimes such as Cloudflare Workers and Deno.

This page arrives with the 0.1.0 release and will show how to load polyjose through WebAssembly and sign and verify your first token.
