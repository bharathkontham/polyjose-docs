title: Swift (iOS)
description: Use polyjose from Swift in iOS apps. The same package also builds for iPadOS, macOS, tvOS, watchOS and visionOS.

This page arrives with the 0.1.0 release and will show how to add polyjose to a Swift project, with iOS as the main target, and sign and verify your first token. The same Swift package also builds for iPadOS, macOS, tvOS, watchOS and visionOS.
